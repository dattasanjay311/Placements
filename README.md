## Selected Projects

### Autoencoder-Based End-to-End Communication System

Implemented a trainable end-to-end communication system using PyTorch, with transmitter and receiver represented as a single neural network and a differentiable AWGN channel.

* Learned a near-optimal QPSK-like constellation from scratch.
* Studied BLER and coding performance against maximum-likelihood decoding.
* Closed 91% of the BLER gap to maximum-likelihood-decoded Hamming(7,4).

### Deep Learning-Based Channel Estimation for OFDM Systems

Built an OFDM communication system from scratch and developed a CNN-based channel-estimation approach.

* Implemented QPSK modulation/demodulation, multipath fading, and cyclic prefix.
* Designed a 1D CNN to learn residual corrections over LS channel estimates.
* Achieved **54.7% lower NMSE** and **33.7% lower end-to-end BER** compared with LS estimation.

### PAPR Reduction Techniques for OFDM Systems

Simulated different PAPR reduction techniques for a 64-subcarrier QPSK OFDM system.

* Implemented Clipping, Selective Mapping (SLM), and Partial Transmit Sequence (PTS).
* Performed Monte Carlo analysis using 20K symbols.
* Studied the trade-off between PAPR, distortion, BER, and power-amplifier back-off.

### Low-Complexity GNSS Signal Acquisition and Doppler Estimation

Studied and implemented a GNSS receiver pipeline involving PRN generation, correlation-based acquisition, and CFAR detection.

* Implemented one-bit quantized Doppler estimation techniques.
* Compared Grid Search, NVLF, and arctangent-based methods.
* Investigated the accuracy-complexity trade-off of low-complexity estimation methods.

### PE-Based Simulator for Underwater Acoustic Communication Channels

Developing a parabolic-equation-based simulation framework for studying underwater acoustic wave propagation.

* Implemented a preliminary Split-Step Parabolic Equation (SSPE) simulator.
* Studied channel effects including multipath propagation and Doppler spread.
* Currently extending the simulator using Padé approximation methods and additional channel/environment models.
